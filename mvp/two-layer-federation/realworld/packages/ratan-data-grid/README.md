# @fm/ratan-data-grid

Status: current build-time grid adapter. It is independent of the active
`@fm/ratan-design-webkit` component package and is not a runtime layer.

Production AG Grid Community adapter for data-intensive Ratan applications. It exposes a bounded row/column/state API and scoped semantic theme. Raw grid configuration/API handles, enterprise modules, host capabilities, and federation delivery are intentionally outside v1.

Peer support: React 18 and AG Grid Community/React 32.3.x. The consuming application owns those peers.
