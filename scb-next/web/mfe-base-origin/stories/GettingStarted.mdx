# Getting Started
##
<h3>This page helps developers to get started and onboard their application into any Micro-frontend Application which adopt <a href="https://single-spa.js.org/docs/getting-started-overview" target="_blank">Single-Spa</a> framework.</h3>
##
<br/>
Browse example stories now by navigating to them in the sidebar.<br/>
View their code in the <a href="https://bitbucket.global.standardchartered.com/scm/ratanrt/mfe-base.git" target="_blank">`https://bitbucket.global.standardchartered.com/scm/ratanrt/mfe-base.git`</a> repository at <a href="https://bitbucket.global.standardchartered.com/projects/RATANRT/repos/mfe-base/browse/stories?at=trunk" target="_blank">`stories`</a> directory to learn how they work.
<div className="mui">
  For Material-UI (MUI) Components, please check this <a href="https://mui.com/material-ui/react-autocomplete/" target="_blank">`page`</a> for more detail and follow the instruction on how to use them out of the box.<br/>
  We have <a href="https://mui.com/material-ui/getting-started/installation/" target="_blank">`installed`</a> Material-UI (MUI) in <a href="https://bitbucket.global.standardchartered.com/scm/ratanrt/mfe-template-container.git" target="_blank">`mfe-template-container`</a> and <a href="https://bitbucket.global.standardchartered.com/scm/ratanrt/mfe-template-tiles.git" target="_blank">`mfe-template-tiles`</a> repositories.<br/>
  If you create your project repository follow the <a href="https://confluence.global.standardchartered.com/display/DSP/Development+Principle+-+Development+Guideline+-+Onboarding+Process" target="_blank">`Onboarding Process Document`</a>, then you do not need to install the <a href="https://mui.com/material-ui/react-autocomplete/" target="_blank">`Material-UI (MUI)`</a> again.<br/>
  You can just imported and use it directly:<br/>
</div>

<div className="mui">
  To use Custom (Input) Components from <a href="https://bitbucket.global.standardchartered.com/scm/ratanrt/mfe-base.git" target="_blank">`mfe-base`</a>, please check the `/src/Root/import/index.ts` in your project repository.<br/>
  It should have similar code with <a href="https://bitbucket.global.standardchartered.com/projects/RATANRT/repos/mfe-template-tiles/browse/src/Root/import/index.ts?at=refs%2Fheads%2Ftrunk" target="_blank">`/src/Root/import/index.ts in mfe-template-tiles`</a>.
  Since it is a Micro-frontend using <a href="https://single-spa.js.org/docs/getting-started-overview" target="_blank">Single-Spa</a> framework, the Application Teams do not need to run `npm install @fm/base`.<br/>
  The `@fm/base` will be accessed on the fly from server defined in the <a href="https://bitbucket.global.standardchartered.com/projects/RATANRT/repos/mfe-root-config/browse/public/importmap.json?at=refs%2Fheads%2Ftrunk" target="_blank">`importmap.json`</a> file.

<div>
  ``` tsx dark
  import React from "react";
  import useController from "./common/useController";
  import Root, { classes, PREFIX } from "./common/style";
  import { ErrorBoundry, CommonUtil, Input, LoadingButton } from "../../Root/import";
  import Comp1 from "../components/Comp1";
  import Comp2 from "../components/Comp2";
  import { MainProps } from "./common/interface";
  import json from "../../../package.json";

  const App: React.FC<MainProps> = (props: MainProps): React.ReactElement => {
    const { loading, setLoading } = useController(props);

    return (
      <ErrorBoundry>
        <div>
          <strong>Version:</strong> {json.version}
          {"  "}
          <strong>Env:</strong> {CommonUtil.getEnv()}
        </div>
        <Root className={classes.root} data-testid={`${PREFIX}`}>
          <section className={classes.section}>
            <div>
              <Input label="label" labelPosition="top" size="medium" />
            </div>
            <div>
              <LoadingButton loading={loading} variant="contained" size="large" onClick={() => setLoading(true)}>Loading button</LoadingButton>
            </div>
            <div>
              <Input label="label" labelPosition="left" size="medium" />
            </div>
            <div>
              <LoadingButton loading={loading} variant="contained" size="large" onClick={() => setLoading(true)}>Loading button</LoadingButton>
            </div>
            <Comp1 />
            <Comp2 />
          </section>
        </Root>
      </ErrorBoundry>
    );
  };

  export default App;
  ```
</div>
