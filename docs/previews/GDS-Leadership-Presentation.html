Design Tokens: Semantic Color System

Naming Convention

--sc-color-{type}-{category}-{role}-{state}

🎨 Background

--sc-color-semantic-bg-primary-rest

For any background-color property

✏️ Foreground

--sc-color-semantic-fg-link-primary-hover

For text and link colors

📐 Border

--sc-color-semantic-border-primary-rest

For border and outline colors

Roles & States

Roles: primary, secondary, destructive, warning, success

States: rest, hover, pressed, selected, disabled

Brand Voice Principles

👤 Human

Warm and approachable, not casual

"Get started" not "Sign up now for free!"

⚡ Dynamic

Accessible to all users, avoid complex punctuation

Clear and straightforward language

🎯 Direct

Simple, no jargon, lead with action

"Request approved" not "Request approved successfully"

Key Writing Rules

  • ✅ Sentence case for all UI elements
  • ✅ UK English spelling
  • ✅ No full stops in buttons/labels
  • ✅ No "successfully", "please"
  • ✅ Active voice
  • ✅ Date format: 3 Nov 2021
  • ✅ Time: 24-hour with timezone
  • ✅ Error = problem + solution

Standard UX Patterns

Modal Patterns

  • Risky Action: Warning → Consequence → Cancel | Proceed
  • Discard: "Discard and leave page?"
  • Delete: "Delete [object]?" with reversal warning
  • Timeout: Session timeout → Sign in again?

Action Buttons

  • Submit form → Submit
  • Save temporary → Draft
  • Confirm warning → Proceed
  • Authorise (checker) → Authorise / Decline
  • Approve (no checker) → Approve / Reject

Error Messages

Empty field: "This field is required"

Invalid format: "This is an invalid [field type]"

Character limit: "Maximum [X] characters"
