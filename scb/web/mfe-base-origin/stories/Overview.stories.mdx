# FM TPT UI Chapter
##
<h3>Welcome to FM TPT UI Chapter for Micro-frontend (MFE).</h3>
##
<br/>
FM TPT UI for MFE is a React Component that implements <a href="https://mui.com/material-ui/getting-started/overview/" target="_blank">Material-UI</a> library and share/ expose them using <a href="https://single-spa.js.org/docs/getting-started-overview" target="_blank">Single-Spa</a> framework.<br/>
It is developed in <a href="https://bitbucket.global.standardchartered.com/scm/ratanrt/mfe-base.git" target="_blank">Base Container</a>.<br/>
<br/>
<h4>FM TPT UI for Standalone React Project can be found here.</h4>
<br/>
<br/>
<h2>Main objectives</h2>
	This FM TPT UI Chapter aims to achieve these main objectives:
		1. To have consistent design language in all components and Web Application/ Portal
		2. To document the common UI components and utilities, use it as reference
		3. To help any team to adopt and implement the common UI components and utilities easily
    4. To share any new or modified or removed common components or utilities in the <a href="https://bitbucket.global.standardchartered.com/scm/ratanrt/mfe-base.git" target="_blank">Base Container</a> or <a href="https://bitbucket.global.standardchartered.com/scm/ratanrt/mfe-root-config.git" target="_blank">Root Config</a> or any other Application Module
<br/>
<br/>
<h2>Community objectives</h2>	
  We also have community objective:
		1. To facilitate the community
		2. To help all the application teams focus on the core business logic instead of reengineer or rework or reinvent the wheel to build the common UI components or utilities
		3. To supports all individual contributors are working together for innovation through collaboration
		4. To build and grow the team where the FM TPT UI components and utilities can be enjoyed by all
