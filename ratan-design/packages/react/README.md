# Ratan Design v2

React implementation of the frozen `@scdevkit/webkit@2.0.5` design contract.

This alpha currently contains the generated parity baseline, exact frozen style
and asset inventories, token metadata, and the first proof component. Stable
`2.0.0` remains gated on the complete in-scope catalogue.

```tsx
import { Button } from '@fm/ratan-design/button';
import '@fm/ratan-design/styles.css';

<Button variant="primary" tone="default" size="sm">
  Confirm
</Button>;
```
