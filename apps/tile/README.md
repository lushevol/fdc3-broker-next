# @fm/template (apps/tile)

## Overview

This application serves as a **Template for creating Tiles**. Tiles are likely discrete UI widgets intended to be displayed within a container application or an **OpenFin** workspace.

## Key Features

- **OpenFin Integration**: Includes `@openfin/core` and types, suggesting it runs in or interacts with the OpenFin container.
- **Data Grids**: Uses `@mui/x-data-grid` for tabular data.
- **Structure**: Contains a sample tile `Tile1` as a starting point.

## Scripts

- `start`: Run dev server.
- `build`: Build for production.
