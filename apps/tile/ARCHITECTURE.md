# Architecture: @fm/template

## Tech Stack

- **Framework**: React 18
- **Microfrontend**: Single-SPA
- **Platform**: OpenFin
- **UI Library**: MUI (Material UI)
- **Language**: TypeScript

## Folder Structure

- `src/Root`: App bootstrapping and routing logic.
- `src/Tile1`: A sample implementation of a Tile component.
- `src/root.tsx`: Single-SPA entry point.

## Concepts

- **Tiles**: Independent, focused UI units.
- **OpenFin**: This app is configured to work within the OpenFin secure runtime, providing native desktop capabilities to the web app.
