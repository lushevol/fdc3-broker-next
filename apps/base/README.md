# @fm/base

## Overview

`@fm/base` is a core microfrontend application within the system, built using **React** and **Single-SPA**. It provides essential infrastructure, shared components, and services to other microfrontends.

## Key Features

- **Component Library**: A set of reusable UI components (AppBar, Drawer, etc.) built on top of Material UI (MUI).
- **Authentication**: Handles login, logout, and token validation via `useServices`.
- **Theming**: Centralized theme definition.
- **Utilities**: Common helper functions and hooks.

## Scripts

- `start`: Run the dev server.
- `build`: Build for production.
- `lint`: Run ESLint.
- `test`: Run Jest tests.
