# @fm/template_container

## Overview

`@fm/template_container` is a feature-rich microfrontend application. It appears to serve as a template or a specific container for complex data views, leveraging **AG Grid** and **Ant Design**.

## Key Features

- **Data Grids**: Built with `ag-grid-react` (Enterprise edition).
- **State Management**: Uses `@reduxjs/toolkit` and `react-redux`.
- **UI Components**: `antd` and `@mui/material`.
- **Data Fetching**: Supports GraphQL via `relay-runtime` and `@apollo/client`, and WebSockets via `sockjs-client`/`stompjs`.

## Scripts

- `start`: Run development server.
- `build`: Build for production.
- `test`: Run tests.
