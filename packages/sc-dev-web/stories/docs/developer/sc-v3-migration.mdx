## Features

* Mobile and tablet updates for dropdown, date input, rating button, button group, time input, menu bar, action bar, layout <sc-tag type="primary">added</sc-tag>
* Storybook mobile support <sc-tag type="primary">added</sc-tag>
* Radio group keyboard accessibility <sc-tag type="primary">added</sc-tag>
* Enhanced `sc-stepper` vertical alginment to always show the active step if there are too many steps <sc-tag type="primary">added</sc-tag>
* Dropdown highlight GDS alignment <sc-tag type="primary">added</sc-tag>
* Multi dropdown supports creating a tag when the value does not exist in the option list <sc-tag type="primary">added</sc-tag>
* Calendar update: supports multiple calendars and mobile <sc-tag type="primary">added</sc-tag>
