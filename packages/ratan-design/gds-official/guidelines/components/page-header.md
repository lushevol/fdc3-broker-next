# Page Header Guidelines

## Overview

Page headers are the main top level component in any page.

---

## Overall

- Title: Page headers have a text font of **28px medium** as the main page title. Page header title is aligned to the left. Page titles are white.
- Description: There can be description below the page title with text font of **14px regular**
- Background: Page header are dark blue in background, using brand's Prosper blue.
- Tabs (optional): Below the main header, there can be a tab group row. The state of the selected tab item will correspond to the background page color.
