## Typography Tokens

### Design Philosophy

- Strong variants available for body text to create emphasis without changing size
- All headings use strong weight by default
- Font sizes and line heights are optimized for UI density and readability
- Typography tokens include font family, size, weight, line height, and letter spacing as a complete style package
- All font style should be using SC Prosper Sans. System fallback font will be Inter. For coding and technical documentations, use Roboto Mono.

### Font Families

**sc-text-hero-main**

- font-style: SC Prosper Sans (with system fallbacks)
- font-size: 56px
- line-height: 72px
- Usage: For hero on content pages e.g. landing pages, splash screens, statistics/numbers. Only use on marketing public-facing sites.

**sc-text-hero-sub**

- font-style: SC Prosper Sans (with system fallbacks)
- font-size: 48px
- line-height: 64px
- Usage: For secondary hero on content pages e.g. landing pages, marketing text, splash screens, statistics/numbers. Only use on marketing public-facing sites.

**sc-text-headline-main**

- font-style: SC Prosper Sans (with system fallbacks)
- font-size: 40px
- line-height: 56px
- Usage: For headlines on content pages e.g. articles, marketing campaigns. Only use on marketing public-facing sites.

**sc-text-headline-sub**

- font-style: SC Prosper Sans (with system fallbacks)
- font-size: 32px
- line-height: 48px
- Usage: For subheadlines and mid-level hierarchy text on content pages e.g. articles, marketing campaigns. Only use on marketing public-facing sites.

**sc-text-section-main**

- font-style: SC Prosper Sans (with system fallbacks)
- font-size: 28px
- line-height: 44px
- Usage: For main primary section headers on pages e.g. articles, headers

**sc-text-section-sub**

- font-style: SC Prosper Sans (with system fallbacks)
- font-size: 22px
- line-height: 38px
- Usage: Use for secondary section breaks and divisions within page content and provides layering for organisation and visual separation.

**sc-text-section-minor**

- font-style: SC Prosper Sans (with system fallbacks)
- font-size: 18px
- line-height: 34px
- Usage: For minor sub headlines on pages e.g. articles, header

**sc-text-title-main**

- font-style: SC Prosper Sans (with system fallbacks)
- font-size: 18px
- line-height: 26px
- Usage: Use for larger component headers and titles e.g. hero cards, feature callouts, important notifications, modal titles

**sc-text-title-sub**

- font-style: SC Prosper Sans (with system fallbacks)
- font-size: 16px
- line-height: 24px
- Usage: Use for secondary component headers and titles that require more hierarchy e.g. hero cards, feature callouts, important notifications, modal titles

**sc-text-paragraph-main**

- font-style: SC Prosper Sans (with system fallbacks)
- font-size: 14px
- line-height: 22px
- Usage: Default body text for page content e.g. standard paragraphs and descriptions on blog posts, articles, general text

**sc-text-component-main**

- font-style: SC Prosper Sans (with system fallbacks)
- font-size: 14px
- line-height: 22px
- Usage: Default text size for basic component text requiring user interaction e.g. button text, placeholder and input text, dropdown item, table cell, anchor navigation

**sc-text-label-main**

- font-style: SC Prosper Sans (with system fallbacks)
- font-size: 12px
- line-height: 16px
- Usage: Use for field labels on top of components e.g. text input, Checkbox, Radio, Switch, Dropdown

**sc-text-description-main**

- font-style: SC Prosper Sans (with system fallbacks)
- font-size: 12px
- line-height: 16px
- Usage: Use for important description text, validation messages or supplementary information e.g. component metadata, error validation, tag labels

**sc-text-helper-main**

- font-style: SC Prosper Sans (with system fallbacks)
- font-size: 12px
- line-height: 16px
- Usage: Use for helper text, very small labels or minor supporting information e.g. badges, small tags, helper text
